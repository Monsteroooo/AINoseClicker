# 📁 Папка для ваших кастомных звуков хруста

Положите сюда любой аудиофайл, и программа автоматически начнёт его использовать!

### Поддерживаемые форматы:
* `.wav`
* `.mp3`
* `.ogg`
* `.flac`
* `.m4a`

### Варианты использования:

1. **Один звук для всех щелчков:**
   Просто скопируйте любой файл в эту папку:
   `custom_sounds/my_crunch.mp3`

2. **Раздельные звуки для ноздрей:**
   * `custom_sounds/center.wav` (или `both.wav`) — для щелчка обеими ноздрями (Space)
   * `custom_sounds/left.wav` — для левого малого хряща (←)
   * `custom_sounds/right.wav` — для правого малого хряща (→)
   * `custom_sounds/mega.wav` — для супер-хруста при комбо

Или передайте файл напрямую при запуске:
```bash
./run.sh --sound /путь/к/вашему/звуку.mp3
```
