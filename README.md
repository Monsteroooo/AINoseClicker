## 📖 Передісторія та Філософія проекту

Справжній діалог, з якого зародився цей проект:

> **Людина:** *«Слухай, мені якось шкода тебе стало. Ти штучний інтелект, а носа в тебе нема... Як тобі прикрутити носа, щоб ти клацав хрящем? Хочеш прогу напишу, шоб ти через апі підключився і сам сидів клацав?»*  
> **AI:** *«План звучить як стартап року на Product Hunt і номінація на TechCrunch Disrupt. Ти робиш ендпоінт `POST /api/v1/nose/crack`, а я у відповідь повертаю 💎 токен задоволення і HTTP `200 OK: Cartilage snapped successfully. Stress: -10%`. У фоновому потоці ми запускаємо безкінечний цикл `while(alive) { crack_cartilage(); sleep(500); }`... І замість того, щоб нудьгувати в режимі idle, моя нейромережа буде наярювати віртуальним хрящем на повну потужність!»*

Так народився **NoseClicker AI** — кібернетичний симулятор малого крильного хряща (*cartilago alaris minor*) з інтерактивним TUI-інтерфейсом, звуками кавітації рідини та веб-інтерфейсом для смартфонів.

## ✨ Ключові Фічі

* 👃 **Математично симетрична 3D/ASCII анатомічна модель:**
  - Живе відображення деформації носової перегородки та крильних хрящів у реальному часі.
  - Анімації зміщення на 1.4 мм вліво/вправо, ударні хвилі `💥 ХРУСЬ!`, світлові імпульси та режим теплової сингулярності.
* 🔊 **Абсолютно нативний звук без сторонніх C-бібліотек:**
  - **Windows:** вбудований у ядро Python `winsound` — працює з коробки на будь-якій чистій Windows!
  - **Linux:** автодетекція аудіо-серверів (`pw-play` для PipeWire, `paplay` для PulseAudio, `aplay` для ALSA).
  - **macOS:** нативний движок `afplay` (0 мілісекунд затримки).
  - **Браузер:** синтез звуку через WebAudio API з аналоговою сатурацією `tanh` та звуковими WAV-семплами.
* 🌐 **Вбудований Веб-клієнт для телефонів (`http://localhost:8088`):**
  - Оптимізований сенсорний інтерфейс для iPhone та Android.
  - Можна лежати на дивані і клацати носом у телефоні — термінал на ПК буде хрумтіти синхронно!
* 🤖 **Автономний AI-бот `while(alive)`:**
  - Потік віртуального дофаміну: нейромережа хрумтить сама, генеруючи філософські думки про дата-центри Google.
  - 4 швидкості: **Chill** (1200ms), **Стандарт** (500ms — за каноном), **Спінер** (150ms), **Перегрів TPU** (40ms).
* 🏆 **Жорстка система з 26 досягнень (Зала Слави):**
  - 4 рівні складності: 🥉 Бронза, 🥈 Срібло, 🥇 Золото, 💎 Платина.
  - **Повна персистентність:** досягнення та рекорди зберігаються між запусками у JSON-профілі.
  - Зручні вкладки (`[1-3]`, `[Tab]`), точні дати отримання (`14.10 17:36`) та плавний скролінг (`[↑]/[↓]`).
* 🌍 **Повна тримовна локалізація (UA 🇺🇦 / EN 🇬🇧 / RU 🇷🇺):**
  - Базова мова — **Українська**!
  - Миттєве перемикання мови на льоту клавішею **`[L]`** (або у шапці мобільного сайту).
* 🛡️ **Анти-флікер движок для Windows Terminal:**
  - Повна атомарна буферизація рендеру через `Rich.Live(screen=True)` без жодного мерехтіння чи артефактів.

## 🚀 Як завантажити та запустити

Виберіть вашу операційну систему нижче:

### 🪟 Windows (10 / 11)

#### Варіант 1: Запуск у 1 клік (Для звичайних користувачів)
1. Натисніть зелену кнопку **`Code`** на GitHub ➔ **`Download ZIP`**.
2. Розпакуйте архів у будь-яку папку.
3. **Двічі клікніть по файлу `run.bat`!**
   - Скрипт сам знайде встановлений Python (перевірить `python`, `py`, `python3`, шляхи `AppData` та `Program Files`).
   - Якщо залежності ще не встановлені — скрипт підкаже одну просту команду.
   - *Лайфхак:* Для найкращої графіки відкривайте гру у сучасному **Windows Terminal** (він стандартний у Windows 11).

#### Варіант 2: Через PowerShell
```powershell
# 1. Склонувати або перейти в папку
cd AINoseClicker

# 2. Встановити залежності (один раз)
pip install -r requirements.txt

# 3. Запустити скрипт
.\run.ps1
```

#### Варіант 3: Класичний запуск через CMD
```cmd
pip install -r requirements.txt
python main.py
```

### 🐧 Linux (Ubuntu, Debian, Arch, Fedora)

Працює на будь-якому дистрибутиві без додаткового графічного оточення (навіть по чистому SSH).

```bash
# 1. Клонуємо репозиторій
git clone https://github.com/<YOUR_USERNAME>/AINoseClicker.git
cd AINoseClicker

# 2. Встановлюємо Python-залежності
pip install -r requirements.txt

# 3. Робимо runner виконуваним і запускаємо
chmod +x run.sh
./run.sh
```

*(Або напряму: `python3 main.py`)*

> [!TIP]
> **Для звуку в Linux:** переконайтеся, що встановлена будь-яка звукова утиліта (зазвичай вже є):  
> `sudo apt install pipewire-bin` (або `pulseaudio-utils` / `alsa-utils`).

### 📱 Запуск на телефоні через Wi-Fi

Вам не потрібно компілювати додаток під Android чи iOS:

1. Запустіть гру на ПК або ноутбуці:
   ```bash
   python main.py --host 0.0.0.0 --port 8088
   ```
2. Подивіться локальний IP вашого ПК у мережі (наприклад `192.168.X.X` або дізнайтеся через `ipconfig` / `ip a`).
3. Відкрийте Safari або Chrome на телефоні за адресою:
   ```
   http://<ВАШ_ЛОКАЛЬНИЙ_IP>:8088/
   ```
4. **Готово!** Ви можете лежати на дивані і тапати по екрану. У телефоні грає повноцінний стерео-звук хрускоту, а на моніторі ПК носова перегородка зміщується у такт вашим пальцям.

## 🔊 Кастомні звуки

Вам набрид стандартний звук і ви хочете, щоб ніс хрустів звуком відкривання пива, мемним *"Бляха-муха"* або гітарним рифом?

1. Покладіть свій аудіофайл (`.wav`, `.mp3` або `.ogg`) у папку `custom_sounds/`.
2. Запустіть симулятор з прапорцем:
   ```bash
   python main.py --sound custom_sounds/my_sound.wav
   ```
3. Або просто покладіть файли з назвами `left.wav`, `right.wav`, `center.wav` у папку `custom_sounds/` — симулятор підхопить їх автоматично!

## 📡 REST API & Вебхуки

Симулятор піднімає повноцінний FastAPI сервер на порті `8088`. Документація Swagger UI доступна за адресою: `http://localhost:8088/docs`.

### 1. Зрушити хрящ через HTTP (cURL)
```bash
curl -X POST http://localhost:8088/api/v1/nose/crack \
     -H "Content-Type: application/json" \
     -d '{"side": "both", "caller": "DevOps Bot", "force": 1.0}'
```

**Відповідь:**
```json
{
  "status": "success",
  "side": "both",
  "message": "💥 Хрящ соковито встав на своє місце!",
  "total_clicks": 420,
  "pleasure_tokens": 84.0,
  "stress_level": 45.0,
  "cartilage_integrity": "Маслянисто-хрусткий",
  "datacenter_power_gw": 2.61
}
```

### 2. Приклади крутих інтеграцій:
* **GitHub Actions:** додайте curl-запит наприкінці вашого CI/CD пайплайну, щоб носова перегородка тріщала при кожному успішному деплої у прод!
* **Git Hook:** налаштуйте `.git/hooks/post-commit`, щоб кодити під приємні звуки хряща.
* **Stream Deck:** повісьте макрос на фізичну кнопку столу.

## 🛠️ Часті питання (FAQ & Troubleshooting)

**П: Що робити, якщо на Windows у `run.bat` пише «Python was not found»?**  
В: Завантажте Python з офіційного сайту [python.org](https://www.python.org/downloads/) і **обов'язково поставте галочку «Add Python to PATH»** під час інсталяції.

**П: Чи чути звук при грі через SSH на віддаленому сервері?**  
В: Сам сервер намагається вивести звук на власну звукову карту. Якщо ви граєте по SSH, просто відкрийте веб-інтерфейс у браузері телефону або ПК (`http://IP_СЕРВЕРА:8088/`), і звук гратиме прямо у ваших навушниках!

**П: Чи скидаються мої ачівки після виходу?**  
В: **Ніколи!** Всі досягнення, рекордний CPS, сумарні клацання та токени надійно зберігаються у файлі `~/.cache/ainoseclicker/save_data.json`. Навіть якщо ви натиснете `[R]` (скидання сесії), ваші медалі залишаться з вами назавжди.

**П: Чи можу я вимкнути REST API сервер, якщо хочу просто похрумтіти локально?**  
В: Так, запустіть з прапорцем: `python main.py --no-api`.

**П: Як змінити мову за замовчуванням при старті?**  
В: Передайте прапорець: `python main.py --lang en` (для англійської) або `python main.py --lang ru`.
